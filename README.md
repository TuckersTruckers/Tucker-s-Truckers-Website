# Tucker’s Truckers — Static Website

A responsive static website built for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About and company story
- `services.html` — Dispatching, coordination, accessorials, analytics, and carrier management support
- `contact.html` — Contact details and email-based inquiry form
- `styles.css` — Shared responsive styles

## Publish with GitHub Pages
1. Create a GitHub repository (or use the repository you want to publish from).
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. If using a custom domain, set it up in GitHub Pages and update your domain DNS records as directed by GitHub.

## Before publishing
- Confirm the phone number, email address, and service wording.
- The contact form uses `mailto:` and opens the visitor’s email app; it does not store submissions. Connect a form provider or backend if you want online form submissions.
- This is a static website; no credentials or API keys are required.
